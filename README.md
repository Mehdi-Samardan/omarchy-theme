# Coppernight

Dark Omarchy theme with deep indigo tones and copper accents.

## Features
- GTK, Hyprland, and terminal styling
- Firefox and app-specific theme files
- Optional icon/cursor setup scripts
- Included wallpapers and preview assets

## Install
```bash
mkdir -p ~/.config/omarchy/themes
cp -r /path/to/omarchy-theme ~/.config/omarchy/themes/coppernight
omarchy theme set coppernight
```

Optional extras:
```bash
cd ~/.config/omarchy/themes/coppernight
./apply-filemanager.sh
./apply-icons.sh
```

## Undo
```bash
cd ~/.config/omarchy/themes/coppernight
./remove-gtk.sh
./remove-icons.sh
```

A modern, dark, high-contrast theme for a clean Omarchy setup.
